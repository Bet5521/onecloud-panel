# OneCloud Panel 用户手册

本手册面向面板使用者，按页面说明功能与典型操作。

## 一、首次使用

1. 浏览器打开面板地址（如 `http://<面板IP>:8080`），自动进入初始化页；
2. 设置管理员用户名（3–32 字符）与密码（8–128 字符）；
3. 提交后自动登录，并弹出 **超级验证码**（10 位）——它是忘记密码时的「保命凭证」，
   请立即抄写保存，弹窗关闭后不再显示；
4. 进入仪表盘。

> 面板没有任何内置默认账号，管理员由首次初始化创建。

## 二、登录与会话

- 输入用户名与密码登录；会话过期时页面顶部提示重新登录；
- 连续失败会触发限流，请稍后再试；
- 右上角用户信息处展开菜单，可维护 **个人信息**（姓名、手机号、通知方式）、
  修改密码或退出登录；姓名与手机号同时用于通知与密码找回。

### 个人信息维护

1. 点击右上角用户头像/用户名，选择 **个人信息**；
2. 可修改：
   - **姓名**、**手机号**（手机号也是短信通知的接收号码）；
   - **通知方式**：`仅记录日志`（默认，不对外发送）/ `邮件`（需填通知邮箱，
     未填则用面板 SMTP 收件人设置）/ `短信`（需填接收手机号，且面板已配置可用短信通道）/
     `通知通道`（从已启用的通道中选择一条）；
3. 保存后立即生效。选择 `通知通道` 时只能挑选启用中的通道；
   选择 `短信` 但面板未配置短信平台时，保存可以通过，但实际发码会明确失败（见下）。

### 忘记密码（自助重置）

1. 登录页点击 **忘记密码？**，输入用户名并选择验证方式：
   - **超级验证码**（默认）：直接使用创建账号/管理员发放的 10 位超级验证码，无需申请；
   - **邮箱**：重置码发送至管理员邮箱（需配置 SMTP），同时输出到面板服务日志；
   - **通知**：重置码按该账号绑定的通知方式**定向**下发（发给本人的邮箱/手机号/指定通道，
     不会广播到其他通道），同时输出到面板服务日志；
2. 邮箱/通知方式需先点 **申请重置码**（8 位，15 分钟内有效；无论用户名是否存在提示相同）；
3. 输入验证码与新密码（8–128 位，需两次一致）→ **重置密码**；
4. 用新密码登录。重置后该账号所有旧登录状态失效，验证码立即作废，
   **超级验证码自动轮换**，页面会弹出新码请重新保存。

> 短信方式重置要求：本人已绑定手机号、面板已在通知管理中配置**可用**的短信通道
> （平台已实现且密钥/签名/模板齐全）。任一条件不满足时，申请会提示
> 「短信平台未配置」或「用户未绑定手机号」，此时请改用邮箱或超级验证码方式，
> 或直接查看面板服务日志中的重置码。

## 三、仪表盘

- 集群概览：节点数量与在线情况、应用数量、任务状态；
- 每个节点一张卡片：内存/磁盘/负载/运行时长，以及该节点的应用安装情况
  （运行/停止/异常计数与列表入口）；
- 最近审计事件：展示具体操作人与动作（登录、任务、设置变更等），而非仅失败记录；
- 权限：需要 `dashboard:read`。

## 四、节点管理

| 功能 | 说明 |
|---|---|
| 节点列表 | 名称、模式（本机/远程）、接入类型、架构、IP、在线状态、资源摘要 |
| 注册令牌 | 生成一次性/限期令牌，可设过期时间与最大使用次数；可删除 |
| 添加节点 | 复制生成的 `install.sh agent ...` 命令到目标机器执行 |
| SSH 添加 | 由面板用 SSH 登录目标机自动执行安装并等待 Agent 上线 |
| 手动添加 | 对特殊网络环境手工录入节点信息 |
| 接入类型 | 局域网（lan）/ 公网（public）/ WireGuard（wireguard）/ 本机（local），默认按地址自动识别，可手动修改 |
| 节点操作 | 编辑、删除、轮换 Agent Token、查看实时信息 |
| Docker | 查看节点 Docker 状态、为节点安装 Docker；可为节点单独配置镜像加速与第三方仓库 |
| 节点终端 | 在浏览器中打开 SSH 终端直连节点（需 node:write），见下文 |
| 存储与 SD 卡 | 查看块设备、挂载/卸载、设置开机自动挂载（写 fstab，nofail 模式），见下文 |

- 远程节点由 Agent 每 30 秒心跳，90 秒内有心跳判定为在线；
- 面板所在主机自动成为「本机节点（local）」，始终在线；
- 接入类型共四种（局域网/公网/WireGuard/本机），按类型筛选节点时列表随即刷新；
  无法解析的地址统一归入「局域网」。

**接入新节点的典型流程（手动）**：节点页生成注册令牌 → 复制安装命令 → 在新机器以 root 执行
→ 回到节点列表看到新节点上线。

### SSH 通道添加节点

无需登录目标机，直接在面板填写 SSH 信息即可完成接入：

1. 节点页点击 **SSH 添加**，填写：
   - **主机**（IP 或域名）、**端口**（默认 22）、**用户名**（通常 root）；
   - **认证方式**：密码，或私钥（粘贴私钥 PEM，加密私钥需另填口令）；
   - **主机指纹策略**：
     - `pin`（默认）：首次连接把目标机指纹回显在任务输出中，之后必须一致，
       可预先填入已知指纹；适合首次接入新机器；
     - `strict`：严格按 `known_hosts` 校验，未知主机直接拒绝；
   - **节点名称**（留空用目标机主机名）与**接入类型**（留空自动识别）；
2. 提交后生成后台任务，弹窗**实时显示**连接与安装输出；
3. 面板登录目标机执行 Agent 安装命令，随后等待 Agent 自动注册（最长 120 秒）；
4. 成功后节点自动出现在列表并置为启用状态，输出中会打印节点 ID、名称、接入类型与地址。

> 若等待超时，输出会提示排查方向：确认目标机可访问面板地址、查看
> `journalctl -u onecloud-panel-agent`。SSH 凭据加密后随任务流转，
> 任务结束后立即清空，不在面板留明文。

> **自签 HTTPS 场景**：面板开启 HTTPS 且使用自签证书时，面板下发的安装命令会附带
> `--insecure`，让 Agent 跳过证书校验回连。这会降低中间人防护能力，
> 建议把自签证书导入目标机信任列表，或改用受信任证书后重新接入节点。

### 节点终端（SSH 直连）

在节点详情的「节点操作」中点击 **打开终端**，即可在面板内获得该节点的交互式 Shell：

1. 填写 **用户名**（默认 root）、**端口**（默认 22）与该节点的 **SSH 密码**——密码仅在本页面内存中使用，不保存、不写日志；
2. 首次连接会先展示目标机主机指纹（SHA256），确认无误后点击 **确认并连接**；之后指纹不一致会被拒绝；
3. 终端支持窗口自适应与缩放，可直接执行命令、编辑文件、查看日志等；断开或关闭弹窗即结束会话；
4. 连接失败（密码错误、网络不通等）会在终端区或提示框中显示原因。

### 存储与 SD 卡

节点详情的「存储设备」区块列出该节点的磁盘与分区（可移动设备带标识）：

- **挂载**：未挂载且有文件系统的设备可点击「挂载」，填写挂载点（默认 `/mnt/sd-<设备名>`），
  可勾选「开机自启」一并写入 fstab；
- **卸载**：已挂载设备可一键卸载；
- **开机自启**：随时可为已格式化设备设置/取消自动挂载。启用时以 UUID + `nofail` 方式写入
  `/etc/fstab`（设备不存在不会阻塞开机），原文件自动备份为 `/etc/fstab.ocp.bak`；
- 设备路径与挂载点不允许空格及特殊字符，防止注入。

### 防火墙管理

节点详情的「防火墙」区块可查看并管理该节点的防火墙（无需登录节点手动敲命令）：

- **自动检测**：面板按 ufw → firewalld → nftables → iptables 的顺序探测节点上
  实际可用的防火墙后端，展示后端类型、启用状态与当前端口规则列表；
  「原始状态输出」可展开查看后端原生状态文本，便于核对；
- **新增规则**：填写端口（单端口如 `53`，或范围如 `50000:50100`）、协议
  （TCP+UDP / TCP / UDP，未指定协议时同时放行/拒绝两种协议）、动作
  （允许 / 拒绝）与可选来源（IP 或网段如 `10.0.0.0/8`，留空表示任意地址）；
  规则可随时在列表中删除；
- **开关防火墙**：ufw / firewalld 后端支持一键开启/关闭（操作前有确认提示，
  关闭防火墙会暴露节点全部端口，请谨慎）；iptables / nftables 后端不支持
  一键开关，需通过节点终端手动管理服务；
- **注意**：iptables 后端的规则为运行时规则，节点重启后失效（页面有提示）；
  nftables 规则增删依赖已有的 filter/INPUT 链；
- 所有操作沿用节点权限（查看需 `node:read`，修改需 `node:write`），
  并记录到审计日志。

## 五、应用管理

- 应用商店按分类展示全部配方，标注支持的部署方式（原生 / Docker）与兼容架构；
- 选择节点与应用后进入安装：填写变量（端口/域名等，配方自带默认值），
  选择部署方式（在配方支持的范围内）；
- **Docker 安装参数覆盖**：容器安装时可展开「高级参数」自定义 **端口映射**、**数据卷**、
  **环境变量** 与 **重启策略**（no/always/unless-stopped/on-failure）。未填写的项沿用配方默认；
  非法格式（如端口缺端口段、路径含空格）会在提交前提示；
- 安装是后台任务，弹窗实时显示进度与输出；
- 应用详情页：状态、健康检查、启动/停止/重启、查看日志、读写配置、卸载（可选清除数据）；
- Docker 方式在未安装 Docker 的节点上会先自动安装 Docker。

**典型流程**：应用页选择 AdGuard Home → 装到本机节点 → 保持默认变量 → 等待任务成功
→ 在应用详情打开 Web 入口 → 不需要时执行卸载。

### SH 脚本管理

应用管理页提供 **脚本** 标签页，可维护常用 Shell 脚本并部署到节点：

1. **新建脚本**：填写名称、描述并粘贴脚本内容（如 `#!/bin/sh` 开头的安装/运维脚本）；
   管理员可勾选「系统级」让所有用户可见，普通用户仅可见自己创建的脚本与系统级脚本；
2. **部署**：选择目标节点并勾选 **开机自启**。脚本写入节点 `/etc/onecloud-scripts/{id}.sh`，
   自启通过 systemd 单元 `ocp-script-{id}.service` 实现（勾选后 enable）；
3. **立即运行**：在选定节点上执行一次脚本，执行过程为后台任务，可实时查看输出；
4. **编辑/删除**：脚本内容更新后，已部署节点的部署记录会因内容 hash 变化提示待更新；
   删除脚本会同时清理部署记录；
5. 权限沿用应用权限（app:read / app:write）。

## 六、用户管理（需要 user:read / user:write）

- 用户列表：用户名、姓名、手机号、角色、状态、创建时间；
- 新建用户：用户名 3–32、初始密码 ≥ 8、分配角色，可填姓名、手机号、
  通知邮箱与通知方式（日志/邮件/短信/通知通道）；
  选择「通知通道」时须指定一条启用中的通道；创建成功弹 **超级验证码**（10 位），
  明文仅显示这一次，请转交用户保存；
- 编辑用户：改姓名/手机号/通知方式/角色、启用/停用、由管理员重置密码；
- **重置验证码**：为用户重新生成超级验证码（旧码立即失效）；
- 删除用户：其会话与重置记录级联清理。

> 超级验证码用于用户本人忘记密码时自助重置，密码重置成功后自动轮换。
> 用户也可在右上角「个人信息」中自行维护姓名、手机号与通知方式。

## 七、角色权限（需要 role:read / role:write）

- 预置角色：管理员（全部权限，受保护不可改）、操作员、只读用户；
- 在角色页勾选/取消权限点后保存即生效，该角色用户下次请求按新权限执行；
- 权限点共 13 个，覆盖仪表盘、节点、应用、用户、角色、审计、设置七个模块。

## 八、审计日志（需要 auditlog:read）

- 按时间倒序展示登录、任务、设置修改等操作，含操作人、IP、结果、详情；
- 可按模块/结果筛选；
- 保留天数由面板设置控制，到期自动清理。

## 九、通知管理（需要 settings:read / settings:write）

支持六种通知通道，用于向用户定向下发密码重置码等重要消息：

| 类型 | 配置要点 |
|---|---|
| WxPusher | APP_TOKEN 必填；UID 列表与主题 ID 至少配一项 |
| Server酱 | SendKey（sct.ftqq.com 获取） |
| 企业微信机器人 | 群机器人 Webhook 地址（https） |
| 钉钉机器人 | 群机器人 Webhook 地址；安全设置选「加签」时填加签密钥 |
| 通用 Webhook | 接收 `POST {title, body, content}` JSON 的 http(s) 地址 |
| 短信 | 选择云平台（阿里云/腾讯云/华为云/百度云），填签名、模板 ID 与平台密钥 |

- **新建/编辑**：选择类型后表单按类型动态变化；密钥字段保存后回显 `******`，
  再编辑时保持不变即可（留空表示不修改）；
- **测试**：点击后向该通道发送一条测试消息，成功后记录「最近测试」时间；
- **启停**：开关即时生效；只有启用状态的通道可被用户选为通知方式。

### 短信通道配置

| 平台 | 必填配置 |
|---|---|
| 阿里云 | AccessKey ID、AccessKey Secret、短信签名、模板 ID、地域（默认 cn-hangzhou） |
| 腾讯云 | SecretId、SecretKey、短信应用 SdkAppId、短信签名、模板 ID、地域（默认 ap-guangzhou） |
| 华为云 / 百度云 | 可保存配置，但发送时提示「暂未实现」，请先使用阿里云或腾讯云 |

- 短信模板中的验证码变量名需为 `code`，模板需先在云平台审核通过；
- **未配置短信平台时无法通过短信收发验证码**：用户选择「短信」方式找回密码时，
  会提示「短信平台未配置」或「用户未绑定手机号」，重置码仍会写入面板服务日志兜底；
- 短信通道只有平台已实现且密钥、签名、模板齐全时才视为「可用」。

## 十、面板设置（需要 settings:read / settings:write）

### 基本设置

面板名称、日志保留天数（0 永久）、GitHub 加速前缀（应用下载走反代）。

### 传输安全（HTTPS）

1. 打开「启用 HTTPS」开关；
2. 选择证书方式：
   - **自动生成自签证书**：可在「证书域名」补充额外域名/IP，其余自动收集；
   - **上传自定义证书**：粘贴证书 PEM 与私钥 PEM，保存前自动校验匹配与有效期；
3. 按需开启「强制 HTTPS」（明文请求 301 跳转，健康检查除外）；
4. 「应用 HTTPS 配置」后确认重启，约 2 秒生效；
5. 关闭开关并重启即恢复纯 HTTP，证书文件保留。

开启后 HTTP 与 HTTPS 在同一端口同时可用，浏览器地址栏把 `http` 改成 `https` 即可，
自签证书首次访问会有警告，选择继续或在客户端导入信任。

### 邮件服务（SMTP）

- 填写主机、端口（465 SSL / 587 STARTTLS / 25）、用户名、密码或授权码、发件地址；
- 「测试收件人」留空则自发自收；先「保存 SMTP」再「发送测试邮件」验证；
- SMTP 用于投递密码重置码；不配置不影响其他功能。

### Docker 镜像加速与第三方仓库（面板级默认）

- **镜像加速地址**：每行一个，如 `https://docker.1ms.run`；留空使用内置默认；
- **第三方仓库**：每行一个，如 `harbor.example.com` 或 `192.168.1.10:5000`
  （即 insecure-registries，HTTP 仓库需配置，HTTPS 仓库无需）；
- 此处为面板级默认值，节点编辑页可为单个节点单独配置，节点配置优先；
- 应用安装拉取镜像时自动生效。

### 版本与运行

展示版本、提交、systemd 状态、监听地址、运行时长、二进制与数据目录路径。

## 十一、移动端与响应式

页面采用响应式栅格，窄屏（手机）自动单列堆叠、表格可横向滚动，
侧边栏可折叠；日常查看状态、审批式操作在手机浏览器可用。
